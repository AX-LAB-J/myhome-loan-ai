# 다른 PC의 Codex에 전달할 프롬프트

아래 내용을 프로젝트를 연 Codex에 전달한다. 이 폴더 전체를 함께 두고, 실제 폴더 위치를 알려준다.

---

이 프로젝트의 기존 프론트엔드·FastAPI 백엔드·DB·OpenAI·네이버지도 연동을 활용하여, 함께 전달한 `mydata-ui-handoff` 폴더의 개발계획서와 Figma 기획대로 모바일 웹을 구현해줘.

먼저 `README.md`와 `01_UI_SPEC.md`~`07_BUTTON_TRACEABILITY.md`를 모두 읽고, 프로젝트의 `AGENTS.md`와 실행 안내를 확인해줘. Figma 원본도 열어 화면을 대조해줘. 이 문서는 다른 PC에서 UI 기획을 검토해 작성했기 때문에, 실제 DB 테이블명·필드명·API·계산 로직·키 이름은 아직 확인되지 않았어. 문서의 제안 이름을 실제 구조라고 가정하면 안 돼.

기존 코드와 DB를 먼저 조사해서 다음을 저장해줘.

1. 실제 스택·실행 방법·기존 기능·미구현 기능을 정리한 `docs/implementation/discovery.md`
2. UI 표시값 → API 응답 → 서비스 계산/변환 → DB 테이블·컬럼·조인·단위·사용자 범위를 연결한 `docs/implementation/data-mapping.md`
3. `06_DECISIONS.md`의 미정 사항별 근거·결론·남은 질문을 기록한 `docs/implementation/decisions.md`
4. `01_UI_SPEC.md`의 버튼 ID를 기존/신규 핸들러와 검수 결과에 연결한 `docs/implementation/traceability.md`

DB는 처음에는 읽기 전용으로 구조·관계·단위·집계 가능성을 확인해줘. 개인정보 전체나 비밀키를 대화·문서·테스트 스냅샷에 출력하지 말고, 스키마·비식별 표본·집계로 확인해줘. 사용자의 원천 금융정보를 덮어쓰지 말고 직접 입력/가정과 구분해줘. 운영 DB를 지우거나 초기화하는 방식은 사용하지 마.

실제 데이터가 합성인지 개인 데이터인지 구분하고 Figma의 ‘합성 데이터’ 표기를 그대로 써도 맞는지 확인해줘. 개발 중 사용자 바꾸기가 실제 다른 고객 정보 접근으로 이어지지 않게 인증·권한과 사용자별 캐시를 확인해줘.

조사만 하고 끝내지 말고 `04_IMPLEMENTATION_PLAN.md` 순서로 구현·연동·검수까지 진행해줘. 기존 디자인 베이스와 사용 중인 라이브러리를 먼저 활용하고, 기획의 화면 배치·버튼·문구를 임의로 리디자인하지 마. 각 화면의 `○○` 자리표시자를 실제 DB/API 값으로 연결해줘. 없는 값은 0이나 가짜 값으로 숨기지 말고 데이터 없음/미지원 상태로 구분해줘.

계산은 기존 백엔드 계산기를 검토하여 한 곳에서 수행하고, LLM은 허용된 조건을 구조화해서 변경하고 계산 결과를 설명하는 역할로 제한해줘. 재무정보/계산 가정 저장 후 재계산 및 AI 대화 새 시작, 조건 되돌리기, 지도·목록 조건 유지까지 구현해줘. OpenAI 및 네이버지도 API 키가 존재한다고 했으니 키의 값은 출력하지 말고 실제 설정 위치·사용 방식·연동 성공 여부를 확인해줘.

화면 수정 주석은 별도 요구사항으로 추적해줘. 특히 지출은 월 총지출만 표시, 자산에 계좌별 잔액 추가, 메뉴명 ‘계산 가정’, 계산 근거 삭제 메모를 반영하되 삭제 범위처럼 모호한 부분은 먼저 코드/기획 근거를 찾아줘. ‘가구 인원수에 따른 거래 추가 예정’은 의미가 확정되지 않은 요구라 임의 기능을 만들어 넣지 마.

구현 선택으로 해결할 수 있는 내용은 스스로 진행해줘. DB/코드에도 없고 제품 의미를 바꾸는 정보만 구체적인 대안과 함께 묶어서 질문하고, 답을 기다리는 동안 독립적인 작업은 계속해줘. 외부 서비스나 데이터가 없어 완수할 수 없는 부분은 가능한 범위를 구현한 뒤 정확한 차단 원인과 필요한 입력을 남겨줘.

마지막으로 `05_ACCEPTANCE.md`에 따라 모바일 화면·모든 버튼·사용자별 데이터·계산 일관성·LLM·지도를 검수하고, `docs/implementation/validation.md`에 실행한 확인과 결과를 기록해줘. 최종 보고에는 변경 파일, 실행 방법, 검수 근거, 미해결 항목을 정리해줘. 배포는 별도 요청 전까지 하지 않아도 돼.

---

권장 전달 방법: 압축을 풀어 기존 프로젝트의 `docs/mydata-ui-handoff/` 등에 복사한 뒤 위 프롬프트와 그 경로를 전달한다. 프로젝트 루트의 기존 `AGENTS.md`를 이 파일로 교체하지 않는다.
